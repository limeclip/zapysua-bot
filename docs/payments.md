# Оплата через Telegram Stars (ZapysUa)

## Як працюють Telegram Stars

- Це внутрішня валюта Telegram. Нічого окремо «вмикати» в налаштуваннях бота не потрібно.
- Бот створює платіжні посилання через `createInvoiceLink`.
- Після оплати Telegram надсилає оновлення `successful_payment` на вебхук.
- Валюта: `XTR`, `provider_token` — порожній рядок.

## Ціни (константи)

Змінюються в одному файлі: `lib/stars-plans.ts`

| Тариф   | Stars | Тривалість |
|---------|-------|------------|
| Місяць  | 250   | 30 днів    |
| Рік     | 2500  | 365 днів   |

## Як отримати тестові Stars

1. Напишіть боту [@durgerkingbot](https://t.me/durgerkingbot).
2. Купіть будь-який бургер за Stars — це додасть тестові зірки на ваш акаунт.
3. Цими зірками можна оплатити підписку ZapysUa.

## Баланс Stars у бота

- Баланс з’явиться лише після **першого успішного платежу**.
- Відкрийте чат з ботом → натисніть на аватар → пункт «Баланс» (якщо є зірки).

## Як тестувати

1. Задеплойте код на Vercel.
2. Переконайтесь, що вебхук бота активний (`/api/webhook`).
3. Відкрийте Mini App → Налаштування → **Підписка та оплата** (`/settings/payment`).
4. Оберіть тариф і натисніть **Оплатити**.
5. Підтвердіть платіж Stars.

### Що перевірити після оплати

- [ ] Лог у Vercel (Functions) — обробник `successful_payment`
- [ ] Статус підписки в Supabase (`subscriptions.status = active`)
- [ ] Зникла блокировка в кабінеті майстра
- [ ] Бот надіслав повідомлення: «Оплату прийнято! Підписка активна до …»

## Можливі проблеми

| Проблема | Рішення |
|----------|---------|
| Вебхук не отримує подію | Перевірте логи Vercel, URL вебхука, `BOT_TOKEN` |
| Платіж не проходить | Валюта `XTR`, `provider_token: ""` |
| Статус не оновився | Перевірте парсинг `invoice_payload` у `lib/bot-payments.ts` |
| 403 у API майстра | Підписка неактивна — перейдіть на `/settings/payment` |

## Файли в коді

- `app/api/stars/create-invoice/route.ts` — створення рахунку
- `lib/bot-payments.ts` — обробка `pre_checkout_query` та `successful_payment`
- `lib/subscription-server.ts` — активація підписки в БД
- `lib/subscription.ts` — перевірка активності (trial / active + дати)
